Primitivas: a derivada ao contrário

No Cálculo I você aprendeu a derivar: dada a função, achar a taxa de variação. Agora a pergunta é a inversa: "que função, quando eu derivo, dá esta aqui?" A resposta se chama primitiva (ou antiderivada), e ela é a porta de entrada de toda a integral.

Receitapergunte "quem derivado dá isso?" → use a tabela termo a termo → some + C → confira derivando

O que é uma primitiva

Definição 1.1 · primitiva
F é primitiva de f  ⇔  F′(x) = f(x)
f
a função que você tem (a "derivada")
F
a função que você procura: derivada dela tem que dar f
exemplo
f(x) = cos x → F(x) = sen x, porque (sen x)′ = cos x

É o caminho de volta: derivar leva F → f; primitivar leva f → F.

Por que sempre aparece o "+ C"

A derivada de um número é zero. Então x³/3, x³/3 + 100 e x³/3 − 7 têm a mesma derivada: x². Todas são primitivas de x². Para escrever todas de uma vez, a gente soma uma constante qualquer C.

Teorema 1.2 · primitiva mais geral
F(x) + C,   C ∈ ℝ
C
constante arbitrária: qualquer número. Achou uma primitiva, achou todas (é só somar C)
no gráfico
cada valor de C sobe ou desce a curva inteira. As curvas são "paralelas": em cada x têm a mesma inclinação
F(x) = x³/3 + C para três valores de C: a mesma curva, só deslocada para cima ou para baixo.

Integral definida: somar retângulos até virar área

Área de triângulo e de retângulo é fácil. Mas e a área embaixo de uma curva? A ideia da aula: encher a região com retângulos, somar, e ir afinando. No limite, com infinitos retângulos fininhos, a soma vira a área exata. Esse limite é a integral definida.

Receitadivida [a, b] em n pedaços de largura Δx → altura de cada retângulo = f(ponto escolhido) → some f · Δx → faça n → ∞

A ideia em três passos

1AproximarCubra a região com retângulos. Sobra ou falta um pouco nas pontas.
2RefinarUse mais retângulos, mais fininhos. O erro diminui.
3No limiteBase → 0 e número de retângulos → ∞: a soma vira a área exata.

A soma de Riemann

Fórmula 2.1 · soma de Riemann
Rn = Σi=1n f(xi*) · Δx     Δx = b − an

f(xᵢ*) · Δx
altura × base = área de um retângulo

Simulador: mexa no número de retângulos

A definição: integral é o limite das somas

Definição 2.2 · integral definida
∫ab f(x) dx = limn→∞ Σi=1n f(xi*) Δx
∫

Integral não é sempre área
Onde f fica abaixo do eixo x, os retângulos têm altura negativa e a integral conta negativo.
Integral = (área acima do eixo) − (área abaixo do eixo). Para a área de verdade, separe os pedaços e some os valores sem sinal.

Como resolver, do começo ao fim (pela definição)

1

Teorema Fundamental do Cálculo: o atalho

O TFC liga as duas metades do cálculo: derivada e integral são operações inversas. Na prática ele troca aquele limite enorme de somas por uma conta de duas linhas: ache a primitiva e faça "valor em cima menos valor embaixo".

Receitaache uma primitiva F → calcule F(b) → calcule F(a) → F(b) − F(a) (sem + C)

Parte 1: derivar uma integral devolve a função

TFC · parte 1
g(x) = ∫ax f(t) dt  ⇒  g′(x) = f(x)
g(x)
a área acumulada de a até x: uma função, porque muda quando x anda
t
variável "de dentro" (muda), só para não confundir com o x do limite
g′(x) = f(x)
a taxa com que a área cresce é a altura da curva ali

Por que funciona: andando um passinho h, a área ganha uma tira de largura h e altura ≈ f(x). Então g(x + h) − g(x) ≈ h · f(x); dividindo por h e fazendo h → 0, sobra g′(x) = f(x).

A área cresce uma tira de altura f(x) a cada passinho h.
Exemplo 1: encontre a derivada de g(x) = ∫₀ˣ √(1 + t²) dt.
  1. É exatamente a forma da parte 1: integral de a (número) até x.
  2. Derivar devolve o integrando trocando t por x.
g′(x) = √(1 + x²)

∫ab f(x) dx = F(b) − F(a) = F(x) |ab
F
qualquer primitiva de f (F′ = f). O + C se cancela na subtração, então nem escreva
F(x) |ₐᵇ
notação para "coloque b, coloque a e subtraia"
em física
∫ v(t) dt = s(b) − s(a): a área sob a velocidade é a distância percorrida

∫₀2π sen x dx = 0: o pedaço de cima (+2) cancela o de baixo (−2).
A área é 2 + 2 = 4. Quando f troca de sinal, separe nos zeros e some os módulos.

Regra da substituição: a regra da cadeia ao contrário

Muitas integrais não estão na tabela, mas têm um "pacote" dentro e, do lado de fora, a derivada desse pacote. A substituição troca o pacote por uma letra nova, u, e a integral feia vira uma da tabela.

Receitaescolha u = o "de dentro" → du = u′ dx → troque tudo para u (não pode sobrar x) → integre em u → volte para x

A ideia

Fórmula 4.1 · substituição
∫ f(g(x)) · g′(x) dx = ∫ f(u) du,   u = g(x)
g(x)
o "de dentro" (o pacote)
g′(x) dx
a derivada do pacote, que tem que aparecer do lado de fora (a menos de um número)
du
= g′(x) dx: é assim que o dx vira du
de onde vem
da regra da cadeia: (F(g(x)))′ = f(g(x)) · g′(x)

1Derivada aparece fora?Escolha u como a parte cuja derivada está multiplicando (sobrar só um número de diferença tudo bem).
2Função composta?Se não, tente u = o "de dentro": o que está dentro do parêntese, da raiz, do expoente, do seno.
3Não deu?É normal errar a primeira escolha. Volte e tente outra.

∫ab f(g(x)) g′(x) dx = ∫g(a)g(b) f(u) du

Integração por partes: a regra do produto ao contrário

Quando o integrando é um produto de dois tipos diferentes de função (x vezes seno, x vezes eˣ, ln x sozinho…), a substituição não resolve. A integração por partes troca a integral difícil por outra mais fácil.

Receitaescolha u pela ordem LIATE → o resto é dv → derive u (du) e integre dv (v) → uv − ∫v du

A fórmula

Fórmula 5.1 · integração por partes
∫ u dv = u v − ∫ v du
u
a parte que você vai derivar (tem que ficar mais simples ao derivar)
dv

du

de onde vem

Objetivo: a integral nova, ∫ v du, tem que ser mais simples que a original. Se ficou pior, troque a escolha de u.

Curvas de nível: o mapa topográfico da função

Uma superfície 3D é difícil de desenhar no papel. A saída é fazer como o mapa de trilha: cortar a superfície em alturas fixas e desenhar cada corte no chão. Cada corte é uma curva de nível.

Receitaiguala f(x, y) = k → escolhe alguns k → isola o y ou reconhece a figura → desenha todas no mesmo plano

f(x, y) = k
k
uma altura travada (um valor fixo de z). Você escolhe o k; a conta acha quais (x, y) chegam nele
z × k
z é a saída livre (muda com o ponto); k é um z congelado
a curva
todos os pares (x, y) com f(x, y) = k: andando por ela você nem sobe nem desce
espaçamento
curvas juntas → a função muda rápido (íngreme) · curvas afastadas → muda devagar (plano)
arraste para girar

1Começar
escreva f(x, y) = k com o k como letra
não escolha número ainda: resolva genérico e troque o k depois

simplifique até reconhecer a figura:
Ax + By = k → reta · x² + y² = r² → círculo · ax² + by² = k → elipse · y = x² + … → parábola

  2. Circunferências centradas na origem, de raio √(9 − k²).

  3. Só pintura (x = 0): 50y = 4000 → y = 80 h.
  4. Misto: x = 25 h → 2000 + 50y = 4000 → y = 40 h.

Integral dupla: volume embaixo de uma superfície

No Módulo 1, a integral somava retângulos embaixo de uma curva e dava uma área. Agora a função tem duas variáveis, z = f(x, y), e o gráfico é uma superfície. Somando caixinhas embaixo dela, sai um volume. É a mesma ideia, um andar acima.

Receitadivida o retângulo em quadradinhos de área ΔA → altura de cada caixa = f(ponto) → some f · ΔA → no limite vira ∬ f dA → calcule por integrais iteradas (Fubini)

Do retângulo para a caixa

Módulo 1 · uma variável
intervalo [a, b] cortado em pedaços Δx
retângulo: altura f(x) × base Δx
soma → área ∫ f(x) dx
Módulo 3 · duas variáveis
retângulo R = [a, b] × [c, d] cortado em quadradinhos ΔA = Δx Δy
caixa: altura f(x, y) × base ΔA
soma → volume ∬ f(x, y) dA
arraste para girar
Superfície z = 16 − x² − 2y² sobre o quadrado R = [0, 2] × [0, 2]. Cada caixa tem base ΔA e altura f no canto de cima. Somando as caixas sai uma estimativa do volume; com caixas cada vez menores, sai o volume exato.

A definição

Definição 15.1 · integral dupla
∬R f(x, y) dA = limm, n→∞ Σi=1m Σj=1n f(xij*, yij*) ΔA
R
a região do chão (aqui, um retângulo [a, b] × [c, d])
m, n
quantos pedaços em x e em y
ΔA
área de cada quadradinho: Δx · Δy
(xᵢⱼ*, yᵢⱼ*)
o ponto escolhido em cada quadradinho para medir a altura
dA
"pedacinho de área"; vira dx dy ou dy dx na hora de calcular
resultado
se f ≥ 0, é o volume do sólido entre a superfície e o chão R. Se f = 1, dá a área de R

Como calcular de verdade: integrais iteradas

Ninguém calcula aquele limite duplo. Integra-se uma variável por vez, exatamente como nas derivadas parciais: congela uma, integra na outra.

Teorema de Fubini · retângulo
∬R f dA = ∫ab [ ∫cd f(x, y) dy ] dx = ∫cd [ ∫ab f(x, y) dx ] dy
de dentro para fora
resolva primeiro a integral de dentro (o colchete), com a outra letra congelada como número
∫ f dy
x é constante: integra só em y. O resultado é uma função de x
depois
integra esse resultado em x, de a até b: sai um número
ordem
num retângulo, as duas ordens dão o mesmo valor (escolha a mais fácil)
truque
se f(x, y) = g(x) · h(y), então ∬ = (∫ g dx) · (∫ h dy)
A integral de dentro (em y, com x parado) dá a área de uma fatia. A de fora soma as fatias. É o "volume por fatias" do Módulo 1.
Propriedades
∬(f + g) = ∬f + ∬g   ∬ c f = c ∬f   f ≥ g ⇒ ∬f ≥ ∬g
linearidade
soma vira soma e número sai para fora, como na integral simples
comparação
superfície mais alta → volume maior
Erros que mais caem
✗ integrar em y e esquecer que x é constante: ∫ x² dy = x² y, não x³/3
✗ trocar os limites: o dy de dentro usa os limites de y
✓ depois da de dentro, a letra dela tem que sumir (só sobra a de fora)

Tipo I · entre duas curvas de x
a ≤ x ≤ b
g₁(x) ≤ y ≤ g₂(x)
uma reta vertical entra sempre pela mesma curva de baixo e sai pela mesma de cima
Tipo II · entre duas curvas de y
c ≤ y ≤ d
h₁(y) ≤ x ≤ h₂(y)
uma reta horizontal entra sempre pela mesma curva da esquerda e sai pela mesma da direita
Tipo I: a reta vertical diz onde y começa e termina. Tipo II: a reta horizontal diz onde x começa e termina.

Inverter a ordem de integração

Algumas integrais duplas são impossíveis numa ordem e fáceis na outra. ∫ sen(y²) dy, por exemplo, não tem primitiva elementar. Mas se a ordem for trocada, aparece um "y" do lado que salva a substituição. Trocar a ordem é redesenhar os limites, não só trocar dx por dy.

Receitaleia os limites e desenhe a região → mude o "olhar" (vertical ↔ horizontal) → escreva os limites novos pelo desenho → calcule

O passo a passo

1LeiaDa integral dada, escreva a região como desigualdades. Ex.: 0 ≤ x ≤ 1 e x ≤ y ≤ 1.
2DesenheCada desigualdade é uma reta ou curva no plano. A região fica entre elas.
3Releia ao contrárioAgora com a outra reta (horizontal se era vertical). Os limites de fora viram números da outra variável.
A mesma região. Olhando na vertical (laranja): 0 ≤ x ≤ 1, x ≤ y ≤ 1. Olhando na horizontal (roxo): 0 ≤ y ≤ 1, 0 ≤ x ≤ y.
Erros que mais caem
✗ trocar dy dx por dx dy e manter os limites: quase sempre fica errado
✗ deixar os limites de fora com letra depois de trocar
✓ confira: a área da região calculada nas duas ordens tem que dar a mesma

Como resolver, do começo ao fim

Stewart, exemplo 15.2.5: ∫₀¹ ∫ₓ¹ sen(y²) dy dx.

1
Começar · ler a região
0 ≤ x ≤ 1 e x ≤ y ≤ 1: triângulo entre y = x, y = 1 e x = 0
∫ sen(y²) dy não tem primitiva elementar: nesta ordem é impossível
2
Desenvolver · reler na horizontal
0 ≤ y ≤ 1 e 0 ≤ x ≤ y → ∫₀¹ ∫₀ʸ sen(y²) dx dy
de dentro (y congelado): sen(y²) · x |₀ʸ = y sen(y²)
3
Finalizar · substituição u = y²
∫₀¹ y sen(y²) dy, u = y², du = 2y dy → (1/2)∫₀¹ sen u du = (1/2)(1 − cos 1)
≈ 0,23
Exemplo: inverta a ordem de ∫₀² ∫x²4 f(x, y) dy dx (só os limites).
  1. Região: 0 ≤ x ≤ 2 e x² ≤ y ≤ 4. É a área entre a parábola y = x² e a reta y = 4, com x ≥ 0.
  2. Na horizontal: y vai de 0 a 4. Para cada y, x vai do eixo (x = 0) até a parábola: x = √y.
  3. Nova integral: ∫₀⁴ ∫₀√y f(x, y) dx dy.
∫₀⁴ ∫₀√y f(x, y) dx dy
Exemplo: calcule ∫₀¹ ∫√y1 ex³ dx dy invertendo a ordem.
  1. ∫ ex³ dx não tem primitiva elementar. Leia a região: 0 ≤ y ≤ 1 e √y ≤ x ≤ 1, ou seja, y ≤ x² com 0 ≤ x ≤ 1.
  2. Na vertical: 0 ≤ x ≤ 1 e 0 ≤ y ≤ x². Nova integral: ∫₀¹ ∫₀x² ex³ dy dx.
  3. De dentro: ex³ · y |₀x² = x² ex³.
  4. De fora com u = x³ (du = 3x² dx): (1/3)∫₀¹ eᵘ du = (e − 1)/3 ≈ 0,573.
